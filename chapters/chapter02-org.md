# Chapter 2 — Notes, Intervals, and the Keyboard

## Learning Objectives

By the end of this chapter, you should be able to:

- Identify the pattern of notes on a piano keyboard.
- Understand whole steps and half steps.
- Count intervals between two notes.
- Recognize the names and qualities of common intervals.
- Understand interval inversion.

---

# Introduction

Every melody, chord, and scale is built from **intervals**—the distance between two notes. Learning intervals is one of the most important steps in understanding music theory.

A piano keyboard is an excellent tool for visualizing intervals because each key represents one distinct pitch.

Even if you do not play the piano, understanding the keyboard layout will make many music theory concepts much easier to learn.

---

# The Piano Keyboard

A standard piano has **88 keys**, consisting of:

- 52 white keys
- 36 black keys

The keyboard follows a repeating pattern.

The black keys appear in groups of:

- Two black keys
- Three black keys

```
⬛ ⬛     ⬛ ⬛ ⬛
⬜ ⬜ ⬜ ⬜ ⬜ ⬜ ⬜
 C D E F G A B
```

This pattern repeats across the entire keyboard.

The note immediately to the left of a group of **two black keys** is always **C**.

Once you find C, the remaining white notes follow naturally:

```
C D E F G A B
```

After B, the pattern repeats:

```
C D E F G A B C
```

---

# White Keys and Black Keys

The white keys are named:

```
A B C D E F G
```

The black keys represent notes that are one semitone higher or lower than adjacent white keys.

For example:

```
C  C♯/D♭  D
```

The black key can be called either:

- C♯ (C sharp)
- D♭ (D flat)

Both names refer to the same key.

---

# Semitones (Half Steps)

A **semitone**, also called a **half step**, is the smallest interval used in most Western music.

On a piano, moving from one key to the next adjacent key is always one semitone.

Examples:

```
C → C♯
E → F
B → C
G♯ → A
```

Notice that:

- There is **no black key between E and F**.
- There is **no black key between B and C**.

These pairs are naturally one semitone apart.

---

# Whole Steps

A **whole step** (also called a **whole tone**) equals **two semitones**.

Examples:

```
C → D
F → G
A → B
```

Another way to think about it:

```
Whole Step = Half Step + Half Step
```

Example:

```
C → C♯ → D
```

Two half steps equal one whole step.

---

# Measuring Intervals

An **interval** is the distance between two notes.

Intervals are named by counting both the starting note and the ending note.

Example:

```
C D
```

Count:

```
C (1)
D (2)
```

Therefore:

```
C to D = Second
```

Another example:

```
C D E
```

Count:

```
C (1)
D (2)
E (3)
```

Therefore:

```
C to E = Third
```

Always include both the starting and ending notes when counting.

---

# Interval Numbers

The basic interval names are:

| Number | Name |
|---------|------|
| 1 | Unison |
| 2 | Second |
| 3 | Third |
| 4 | Fourth |
| 5 | Fifth |
| 6 | Sixth |
| 7 | Seventh |
| 8 | Octave |

Examples:

```
C → C = Unison

C → D = Second

C → E = Third

C → F = Fourth

C → G = Fifth

C → A = Sixth

C → B = Seventh

C → C = Octave
```

---

# Interval Qualities

The number tells **how many letter names** are involved.

The **quality** tells the exact size.

Common qualities include:

- Major
- Minor
- Perfect
- Augmented
- Diminished

For example:

```
C → E
```

is a **Major Third**.

But:

```
C → E♭
```

is a **Minor Third**.

Both are thirds because they span three letter names, but they contain different numbers of semitones.

---

# Major and Minor Intervals

The following intervals may be either **major** or **minor**:

- Second
- Third
- Sixth
- Seventh

Examples:

| Interval | Semitones |
|----------|-----------|
| Minor Second | 1 |
| Major Second | 2 |
| Minor Third | 3 |
| Major Third | 4 |
| Minor Sixth | 8 |
| Major Sixth | 9 |
| Minor Seventh | 10 |
| Major Seventh | 11 |

A major interval is one semitone larger than the corresponding minor interval.

---

# Perfect Intervals

Some intervals are classified as **perfect** instead of major or minor.

These include:

- Unison
- Fourth
- Fifth
- Octave

Examples:

| Interval | Semitones |
|----------|-----------|
| Perfect Unison | 0 |
| Perfect Fourth | 5 |
| Perfect Fifth | 7 |
| Perfect Octave | 12 |

These intervals are considered especially stable and consonant.

---

# Augmented and Diminished Intervals

An interval can be made larger or smaller.

- Increase a perfect or major interval by one semitone → **Augmented**
- Decrease a perfect or minor interval by one semitone → **Diminished**

Examples:

```
Perfect Fifth

C → G
```

Increase by one semitone:

```
C → G♯
```

Result:

```
Augmented Fifth
```

Decrease by one semitone:

```
C → G♭
```

Result:

```
Diminished Fifth
```

Another example:

```
Major Third

C → E
```

Raise E to E♯:

```
Augmented Third
```

Lower E to E♭:

```
Minor Third
```

Lower E♭ to E𝄫 (E double flat):

```
Diminished Third
```

> **Note:** Although some augmented and diminished intervals sound the same as other intervals on instruments using equal temperament (such as a piano), they are written differently because they serve different harmonic functions.

---

# Interval Inversion

An interval can be **inverted** by moving one note up or down by an octave.

For example:

```
C → E
```

This is a **Major Third**.

Invert it:

```
E → C
```

This becomes a **Minor Sixth**.

The interval number changes according to this rule:

| Original | Inversion |
|----------|-----------|
| Unison | Octave |
| Second | Seventh |
| Third | Sixth |
| Fourth | Fifth |
| Fifth | Fourth |
| Sixth | Third |
| Seventh | Second |
| Octave | Unison |

A useful rule:

> **The interval numbers of an interval and its inversion always add up to 9.**

Examples:

```
Third + Sixth = 9

Fourth + Fifth = 9

Second + Seventh = 9
```

Interval qualities also invert:

| Original | Inversion |
|----------|-----------|
| Major | Minor |
| Minor | Major |
| Perfect | Perfect |
| Augmented | Diminished |
| Diminished | Augmented |

---

# Why Intervals Matter

Intervals are the foundation of many musical concepts.

They are used to build:

- Scales
- Chords
- Melodies
- Harmony
- Counterpoint

For example:

- A major chord contains a **Major Third** and a **Perfect Fifth**.
- A minor chord contains a **Minor Third** and a **Perfect Fifth**.
- A major scale is defined by a specific sequence of whole and half steps (covered in Chapter 5).

Understanding intervals makes it much easier to recognize patterns in music.

---

# Key Takeaways

- The piano keyboard follows a repeating pattern of seven white keys and five black keys.
- A semitone (half step) is the smallest interval in Western music.
- A whole step equals two semitones.
- Intervals are named by counting the letter names from one note to another.
- Intervals have both a number (such as Third or Fifth) and a quality (such as Major or Perfect).
- Major and minor intervals differ by one semitone.
- Perfect intervals include the unison, fourth, fifth, and octave.
- Augmented intervals are one semitone larger than perfect or major intervals.
- Diminished intervals are one semitone smaller than perfect or minor intervals.
- Inverting an interval changes both its number and, in most cases, its quality.
